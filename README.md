# 桌边煎蛋 · Desktop Skillet

Mac 桌面上的一口小锅。插电点火，CPU 忙时颠锅，通知横幅出现时溅出油花，接入扩展屏时滑蛋装盘。解锁时看看这枚蛋煎到了几分熟。

[产品介绍与安装说明](https://harnessloom.com/desktop-skillet/) · [下载 1.0.0 通用 DMG](https://harnessloom.com/downloads/Desktop-Skillet-1.0.0-universal.dmg)

打开 DMG，将「桌边煎蛋」拖入「应用程序」并启动。从菜单栏的平底锅选择「试播效果」即可体验。支持 macOS 14 或更高版本，安装包包含 Apple 芯片与 Intel 两种架构。此版本使用本地签名，尚未经 Apple 公证。

下载同版本的 SHA256SUMS.txt 后，可用 `shasum -a 256 -c SHA256SUMS.txt` 核对同目录的 DMG。
